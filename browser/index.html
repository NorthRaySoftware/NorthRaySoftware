About

NorthRay Browser is a desktop web browser for Windows. Web pages are shown by Microsoft Edge WebView2, the Chromium engine that comes with Windows 11 and is kept up to date by Windows, with its sandbox left fully on. It has tabs; an address bar that opens addresses, local files and searches (and never sends a file path or a local network address to a search engine); a start page with your bookmarks; bookmarks with folders, a bookmarks bar and a bookmarks page, imported from or exported to Chrome, Edge and Firefox; and saved passwords and form filling, kept encrypted on your PC by the engine's password manager. Certificate errors are always refused. History, a downloads panel, profiles, private windows and the creative tools (collections, notes, boards and more) come in later versions.

Features

  • Tabs: open, close, reopen closed tabs, switch with the keyboard; links that open new windows open as tabs
  • Address bar: web addresses, local files and searches with DuckDuckGo, Google, Bing or another engine; file paths and local network addresses are never searched for
  • Bookmarks: a star in the address bar, a bookmarks bar, folders, a bookmarks page with search, and import and export in the format Chrome, Edge and Firefox use; a daily backup
  • A start page with a greeting, a search field, your bookmarks as tiles and recently closed tabs; nothing on it loads from the internet
  • Saved passwords and form filling, offered after you sign in, encrypted with a key protected by your Windows account; turn them off or delete them all from the menu
  • A padlock for secure sites and a plain "Not secure" for others; certificate problems are refused with an explanation
  • Full screen, printing, developer tools, and light and dark themes that follow Windows
  • Edge's sandbox and SmartScreen protection against phishing and harmful downloads; no telemetry of NorthRay's own

What's new

Version 0.4.0 · 2026-11-14

  • Downloads page (Ctrl+J, the menu, or the new button by the menu): every download with its progress and time left, Pause, Resume and Cancel while it runs, Open and Show in folder when it's done, and Download again if it failed. The list is kept between sessions; a tab closed mid-download finishes it first.
  • Ads and trackers are blocked: requests to about 120 well-known advertising, tracking and data-collection services are refused when they're on a different site from the page, so pages load faster and fewer companies follow you around. A site's own content is never blocked.
  • The shield in the address bar shows how many were blocked on the page, and turns blocking off for a site that doesn't work properly (or everywhere).
  • Google is the default search engine. If you chose another one yourself, it's kept.
  • History, Bookmarks and Downloads still open when web pages can't be shown.

Version 0.3.3 · 2026-11-14

  • Messages and questions (“Delete this?”, “Saved”) now appear in a NorthRay dialog that matches the app, instead of the plain grey Windows box.
  • The side tabs’ title and the tabs you're not on are easier to read.

Version 0.3.2 · 2026-11-14

  • Text on the night sky stays clear: stars keep away from the words in title bars and sidebars.

Version 0.3.1 · 2026-11-14

  • The small text links are now proper buttons.
