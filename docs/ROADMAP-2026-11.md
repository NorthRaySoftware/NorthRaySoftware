# NorthRay suite roadmap (from CJ's answers, 14 November 2026)

Ten questions per app; these are the decisions. "All" means every listed priority area is wanted.

## NorthRay Launcher
Done in 0.19.0 (14 November 2026): all ten. Also, at CJ's request, every app now draws minimise, maximise and close in its own top area.

1. Updates install **automatically** in the background when the app isn't open.
2. Start with Windows: **off, with a setting**.
3. Library: **big app cards** (artwork, version, Open).
4. Extras: **tray icon with quick-launch**.
5. First run: **short 3-step welcome tour**.
6. CJ Philip apps: **their own "Optional" section at the bottom**.
7. Install location: **default per-user folder, changeable in Settings**.
8. Themes: **Light, Dark, follow Windows**.
9. Downloads **checked against the catalogue checksum** before installing.
10. Priority: **all** (auto-updates + tray, look and feel, install location + safety).

## NorthRay Writing Studio
Stage 1 done in 0.20.0: focus/typewriter mode, font and page width (9), spell check switch and first style hints (2; better hints and custom rules done in 0.21.0, rules kept per world or per independent book), linked names (4, in the text), backups every 30 minutes and to a chosen folder (6). Version history per chapter already existed (Review > Changes, and the details panel).
Stage 3 done in 0.23.0: image boards (5) and linked wiki pages in Worldbuilding (4); the Studio's own spell checker with per-world dictionaries (2).
Stage 2 done in 0.22.0: timeline, corkboard and story-structure templates (8). Also: names link by their parts, shared names link to everyone who has them, themed menus, name cards.

1. Used for **novels/series and comics/scripts equally**.
2. Next tools: **focus/typewriter mode, version history per chapter, spell check + style hints**.
3. Exports: **EPUB (improve styling and covers), print-ready PDF, comic script format**.
4. World bible: **linked wiki pages** (names in the text link to their page).
5. Art: **image boards** (character sheets, covers).
6. Backup: **local auto-backup plus a folder you pick** (e.g. OneDrive).
7. Review: **share a review copy** (export for a beta reader, import their comments).
8. Plotting: **timeline view, corkboard/index cards, story-structure templates**.
9. Editor: **font and page-width choices**.
10. Priority: **all**.

## NorthRay Browser
1. Next: **history page + search, downloads panel, ad/tracker blocking**.
2. Default search engine: **Google**.
3. Creative tools first: **reference board (save images), image/colour picker from pages**.
4. Tabs: **vertical tabs option**.
5. Sync: **none, local only** (export/import file).
6. Extensions: **never**.
7. Start page: **custom background image, weather/clock, notes widget**.
8. Private browsing window: **no**.
9. Default browser: **offer once, with a setting**.
10. Priority: **all**.

## NorthRay Files
1. File actions: **copy/move/paste, rename, new folder, delete to Recycle Bin**.
2. Layout: **tabs and two side-by-side panes**.
3. Creative tools: **tags + colour labels, collections (virtual folders), gallery view for art folders, preview pane**.
4. Search: **instant search in the folder and whole-PC search via the Windows index**.
5. Thumbnails also for: **videos, PDFs, PSD/Procreate**.
6. Right-click: **NorthRay menu with "More options"** (Windows' own menu behind it).
7. Sidebar: **pinned folders (drag to pin), Recycle Bin, folder tree**.
8. Folders **refresh by themselves** when files change.
9. Replace File Explorer as default: **optional setting, later**.
10. Priority: **all**.

## CJ Philip Community (optional, from the Launcher)
1. Purpose: **a hub for CJ's work**.
2. Shows: **latest YouTube videos, Twitch live status**.
3. Alerts: **Windows notifications** when CJ goes live or posts.
4. SkillSwap: **dropped**.
5. Discord: **just a join button**.
6. Home page: **next CJ Radio show with a countdown**.
7. News section: **none**.
8. Look: **keep the current CJ style**.
9. Start with Windows / tray for alerts: **optional setting, off by default**.
10. Priority: **all**.

## CJ Radio (opens only from CJ Philip Community)
1. Listening: **sound-only Twitch by default**, video one click away.
2. Recordings: **from the GitHub repo The-CJ-Philip-Show** (not YouTube uploads).
3. Call-ins: **"Call in" button opens the Discord voice channel**, with the 16+ notice.
4. Extras: **Twitch chat, mini player that stays on top, show reminder notifications**.
5. Schedule: **Google Calendar, as now**.
6. Off air: **next-show countdown + latest recording**.
7. Audio: **volume, mute, media keys**.
8. Look: **big "ON AIR" studio look**.
9. Now playing: **segment title from the Twitch stream title**.
10. Priority: **all**.
