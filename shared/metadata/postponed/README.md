# Postponed applications

Apps here are not part of the launch. Their code is kept (for SkillSwap: `apps/skillswap`, `libs/cjcore` SkillSwap rules and `shared/metadata/skillswap`), but the launcher, the website and the installers don't list them. To bring one back, move its JSON file into `apps/` and switch its build option on (`-DCJ_BUILD_SKILLSWAP=ON`).
