# Abandoned applications

**SkillSwap is not coming back** (the project director's decision, 26 November 2026). It isn't part of NorthRay: the launcher, the website and the installers don't list it, and its app source was never in this repository. The old build option (`CJ_BUILD_SKILLSWAP`) pointed at that missing folder and has been removed.

What's left is dormant: its rules in `libs/cjcore` (`skillswap.cpp`, still covered by `cjcore_tests`), this folder's `skillswap.json`, `shared/metadata/skillswap/` and `shared/metadata/demo/skillswap.demo.json`. They can be deleted whenever the director agrees.
