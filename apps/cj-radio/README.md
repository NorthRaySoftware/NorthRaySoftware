# CJ Radio

`CJRadio.exe`: a standalone Windows app (it keeps playing when the launcher is closed).

- **Listen**: live status from the station server, Listen live, call-in requests while live, coming up, latest recording.
- **Schedule**: confirmed programmes only, as a list or a month grid with Saturdays shaded.
- **Recordings**: past shows from the recordings index.
- **Presenter** (only on a PC with presenter mode switched on): station checks and the going-live steps for OBS + SE.Live.

Configuration lives in `shared/metadata/radio/station.json`. Setup: `docs/CJ-RADIO-SETUP.md`.

Keyboard: Ctrl+1 to Ctrl+4 switch pages, Ctrl+P play or stop, Ctrl+M mute, Ctrl+Up/Down volume, F5 refresh.
