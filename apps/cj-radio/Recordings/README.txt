CJ Radio recordings
===================

Put finished show recordings here as MP3 files. CJ Radio lists every .mp3 in
this folder on its Recordings page and plays it from the PC, no internet needed.

Name each file with the date first, then the title:

    2026-11-14 The CJ Philip Show.mp3

Optional: add a recordings.json file here for descriptions and lengths:

    {"recordings": [
      {"file": "2026-11-14 The CJ Philip Show.mp3",
       "title": "The CJ Philip Show",
       "presenter": "CJ Philip",
       "durationMinutes": 120,
       "description": "Listener questions and Alvora news."}
    ]}

Check each recording before adding it, especially any caller segments.
Files added to an installed copy are replaced when CJ Radio updates; to send
recordings to listeners, add them to this folder in the project and rebuild.
